# Часть 1. Информация о процессоре через WMI
Предположение: программа покажет 2 физических и 2 логических ядра.
Выдал:
Название: Intel(R) Pentium(R) CPU 2030M @ 2.50GHz
Ядер: 2
Логических процессоров: 2
В диспетчере устройств 2 процессора.
Данные программы и данные Диспетчера устройств совпали.
Environment.ProcessorCount тоже вернёт 2 - это число логических процессоров, а не физических ядер.
Это технология Hyper-Threading: одно физическое ядро умеет параллельно обрабатывать два потока команд, поэтому ОС видит его как два логических процессора.
