# Часть 1. Информация о процессоре через WMI
Прогноз: программа покажет 2 физических и 2 логических ядра.
Выдал:
Название: Intel(R) Pentium(R) CPU 2030M @ 2.50GHz
Ядер: 2
Логических процессоров: 2
В диспетчере устройств 2 процессора.
Данные программы и данные Диспетчера устройств совпали.
Environment.ProcessorCount тоже вернёт 2 - это число логических процессоров, а не физических ядер.
Это технология Hyper-Threading: одно физическое ядро умеет параллельно обрабатывать два потока команд, поэтому ОС видит его как два логических процессора.
# Часть 2. Информация о дисках
Прогноз: программа найдёт 1 физический диск (SSD).
Выдал:
Модель: Generic Flash Disk USB Device
Размер: 14,6 ГБ
Модель: CT240BX500SSD1
Размер: 223,6 ГБ
Прогноз не оправдался. Данные программы и данные Диспетчера устройств совпали. Программа обнаружила 2 логичесикх диска. В Проводнике видно 1 логический диск (C:). В Диспетчере устройств -> «Дисковые устройства» 2 устройства.
Физический диск - это само устройство (HDD/SSD). Логические диски - это разделы на нём (C:, D: и т. п.). Один физический диск может быть разбит на несколько логических разделов.
# Часть 3. Что ещё «знает» WMI
Прогноз: WMI покажет не только оборудование, но и сведения об ОС.
Выдал:
ОС: Майкрософт Windows 10 Домашняя для одного языка
Версия: 10.0.19045
WMI - это единый интерфейс для получения сведений о системе. Программы используют один и тот же механизм запросов, а Windows сама собирает данные из разных источников и отдаёт их в едином формате.

# Вопросы на осмысление
1.	Windows получает сведения о процессоре, дисках и USB‑устройствах через WMI (Windows Management Instrumentation). Это как единый «информационный центр» системы: он собирает данные от драйверов и других частей ОС. Обращаться напрямую к устройству обычно не нужно - WMI сам берёт нужные сведения из системы.
2.	Доступ к оборудованию - это не базовая функция, а специализированная. Она нужна не всем программам, зависит от ОС. Поэтому её вынесли в отдельный пакет, чтобы не усложнять и не раздувать базовый .NET.
3.	Это говорит о том, что WMI предоставляет динамические сведения: при каждом запросе он собирает актуальные данные из системы, а не отдаёт заранее сохранённую копию.
4.	Это говорит о том, что и Диспетчер устройств, и ваша программа берут данные из одного общего источника - системных служб Windows (в том числе WMI и драйверов), поэтому сведения совпадают.
